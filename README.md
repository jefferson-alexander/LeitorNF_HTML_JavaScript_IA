🧾 Leitor de Notas Fiscais com Inteligência Artificial

Aplicação web desenvolvida para extrair automaticamente informações de notas fiscais a partir de imagens utilizando Inteligência Artificial.

O usuário envia uma imagem da nota fiscal e a aplicação utiliza a IA através do Puter.js para identificar os produtos, seus respectivos valores e o valor total da compra.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, com execução em um servidor local através do XAMPP.


🧠 Inteligência Artificial

A aplicação utiliza o Puter.js para realizar a comunicação com os recursos de Inteligência Artificial.
A imagem da nota fiscal é enviada para processamento e a IA analisa seu conteúdo.

O objetivo é transformar uma informação presente em uma imagem em dados estruturados que podem ser utilizados pela aplicação.


⚙️ Como executar o projeto

Como o projeto utiliza o Puter.js e recursos de Inteligência Artificial, a aplicação deve ser executada através de um servidor local.

1️⃣ Instale o XAMPP

Faça a instalação do XAMPP em seu computador.

Após a instalação, abra o XAMPP Control Panel.

2️⃣ Inicie o Apache

No XAMPP, inicie o serviço:

Apache

Quando o Apache estiver ativo, ele ficará disponível para executar a aplicação localmente.

3️⃣ Copie o projeto

Coloque a pasta do projeto dentro do diretório:

C:\xampp\htdocs\

Por exemplo:

C:\xampp\htdocs\leitor-notas-fiscais\
4️⃣ Acesse a aplicação

Abra o navegador e acesse:

http://localhost/leitor-notas-fiscais/

A aplicação estará disponível no navegador.
